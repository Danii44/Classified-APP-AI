✓ RLS POLICIES (Permission Rules)
==================================

profiles table:
- SELECT: Everyone can see all profiles
- INSERT: Only when auth.uid() = id
- UPDATE: Only own profile
- DELETE: Only own profile

products table:
- SELECT: Active products visible to all + own drafts
- INSERT: Own products only
- UPDATE: Own products only
- DELETE: Own products only

favorites/messages/conversations:
- SELECT: Own only
- INSERT/UPDATE/DELETE: Own only
